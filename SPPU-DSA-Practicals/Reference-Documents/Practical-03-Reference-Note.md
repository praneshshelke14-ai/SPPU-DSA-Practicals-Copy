# Practical 3 – uploaded reference note

The Practical 3 DOCX was reviewed from its extracted attachment content. Its original DOCX binary was not present in the mounted upload directory when this archive was assembled, so it could not be copied alongside the other original documents.

The uploaded problem statement is: implement a telephone-book database using a hash table and demonstrate Linear Probing, Double Hashing and Quadratic collision handling. The extracted uploaded code contained a `node` record with name, telephone and key, a character-code-sum hash, and create/search/update/delete/display operations. The extracted code implemented Linear Probing only and contained an index mismatch in deletion. The prepared runnable program is saved as `../Practical-03-Hashing/telephone_directory.cpp`; its README explains the added probing methods and corrections.
