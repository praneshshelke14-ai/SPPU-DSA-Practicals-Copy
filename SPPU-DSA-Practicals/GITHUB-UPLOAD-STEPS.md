# Upload this folder to GitHub

1. Extract `SPPU-DSA-Practicals.zip`.
2. Open GitHub Desktop and sign in.
3. Choose **File → Add Local Repository** if this extracted folder is already a Git repository, or choose **File → New Repository** and set the local path to the extracted `SPPU-DSA-Practicals` folder (do not create an extra nested folder).
4. Review the detected files in the Changes tab.
5. Enter a commit summary such as `Add SPPU DS practical source and notes`.
6. Click **Commit to main**.
7. Click **Publish repository**. Choose Private if this is personal exam material.
8. To upload future edits, save the files, commit the changes and click **Push origin**.

You can also create an empty repository on github.com and use the GitHub Desktop **Publish repository** option. Do not upload passwords, API keys or other secrets.
